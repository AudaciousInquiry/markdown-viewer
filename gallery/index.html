Using AWS icons in Mermaid

Reference an icon as aws:name inside an architecture-beta diagram. Click any icon below to copy its name. 

```mermaid
architecture-beta
    group vpc(aws:group-vpc)[Production VPC]

    service web(aws:ec2)[Web Tier] in vpc
    service api(aws:lambda)[API] in vpc
    service db(aws:rds)[Database] in vpc
    service store(aws:s3)[Object Store]

    web:R --> L:api
    api:R --> L:db
    api:B --> T:store
```

Icons only render in architecture-beta diagrams. Other diagram types have no icon slot. Names are matched exactly and are always lower case.

No icon matches that name.

Try a shorter word. Most services are filed under their product name with AWS- and Amazon- removed, so Amazon CloudFront is aws:cloudfront.

No icon pack is installed

The AWS Architecture Icons are not redistributed with this extension. To install them, download the asset package from aws.amazon.com/architecture/icons, unpack it, and rebuild with AWS_ICONS_DIR pointing at the unpacked folder: 

AWS_ICONS_DIR=/path/to/asset-package sh build/package.sh chrome
